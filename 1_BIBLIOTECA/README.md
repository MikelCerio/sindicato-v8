# 📚 1_BIBLIOTECA

Carpeta para tu biblioteca de inversión **personal**.

- ✅ Se versionan: informes oficiales presentados ante la SEC (10-K, 10-Q), que son documentos públicos.
- 🚫 No se versionan (ver `.gitignore`): libros, cartas y webs con copyright.
  Guárdalos aquí en tu ordenador o en tu Drive privado; el indexador (`index_biblioteca.py`)
  los leerá igualmente en local.

Las cartas de Buffett se pueden leer gratis en la web oficial de Berkshire Hathaway:
https://www.berkshirehathaway.com/letters/letters.html
